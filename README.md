# Simple Image Editor

貼上截圖、快速標註、複製帶走的網頁工具。影像只在瀏覽器內處理，不會上傳。

**線上使用：** <https://jayshihchou.github.io/simple-image-edit/>

## 使用流程

1. 截圖後在頁面按 `Ctrl V`（也可以拖曳檔案或開啟檔案）
2. 用工具標註
3. 結果會自動複製到剪貼簿，直接貼到任何地方即可

**自動複製**預設開啟，每次用左側工具編輯後都會把結果放進剪貼簿（加入圖層、復原、「影像」選單的操作不會觸發）；可用「複製」鈕旁的開關關閉，之後改按「複製」或 `Ctrl C`。

**畫到圖片外**：箭頭、文字等標註可以放在原圖範圍外，輸出會自動延伸到涵蓋所有標註並留一點邊，延伸的部分用編輯區的底色填滿。適合截圖很小、說明很長的情況。

已經有圖時再貼上（或拖曳檔案），會詢問要**開新圖**還是**加入為圖層**，按 `1` / `2` 或 `Enter` 選建議項。兩種都可以復原。

## 工具

| 工具 | 快捷鍵 | 說明 |
| --- | --- | --- |
| 選取 | `V` | 移動、縮放、改樣式，`Shift` 拖曳控制點鎖定比例，雙擊文字可編輯 |
| 裁切 | `C` | 自由或固定比例，`Shift` 拖曳角落鎖定比例，`Enter` 套用 |
| 箭頭／直線 | `A` / `L` | `Shift` 鎖定 45° 角 |
| 方框／橢圓 | `R` / `O` | 可填滿，`Shift` 畫正方形或正圓 |
| 畫筆／螢光筆 | `P` / `H` | `Shift` 畫直線 |
| 文字 | `T` | 支援多行與標籤底色 |
| 步驟編號 | `N` | 自動遞增，刪除後重新編號 |
| 塗黑 | `X` | 用實色完全覆蓋 |
| 馬賽克／模糊 | `M` / `B` | 遮住較不敏感的內容 |
| 聚光 | `S` | 框選區域以外變暗 |

「影像」選單另有旋轉、翻轉、調整尺寸、邊框與圓角。按 `?` 可查看完整快捷鍵。

> 密碼、金鑰等機密資料請用**塗黑**。馬賽克和模糊在部分情況下可能被還原或辨識。

## 開發

純靜態網站，沒有相依套件，也不需要建置。

```sh
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。剪貼簿 API 需要 HTTPS 或 localhost。

## 部署

推送到 `main` 後由 GitHub Actions（`.github/workflows/pages.yml`）發布到 GitHub Pages。部署時會把 `__V__` 換成 commit 版本號，讓 `index.html` 一定載入同一版的 `style.css` 和 `js/app.js`，避免瀏覽器快取混用新舊檔案。本機開發不需要替換。

repo 的 **Settings → Pages → Source** 要設為 **GitHub Actions**。
