# 截圖快編

貼上截圖、快速標註、複製帶走的網頁工具。影像只在瀏覽器內處理，不會上傳。

**線上使用：** <https://jayshihchou.github.io/simple-image-edit/>

## 使用流程

1. 截圖後在頁面按 `Ctrl V`（也可以拖曳檔案、開啟檔案或擷取畫面）
2. 用工具標註
3. 按 `Ctrl C` 複製結果，貼到任何地方

編輯後再貼上新圖，會加入為可移動的圖層；原圖未改動或已複製過，則會直接換成新圖。兩種情況都可以從提示切換，也可以復原。

## 工具

| 工具 | 快捷鍵 | 說明 |
| --- | --- | --- |
| 選取 | `V` | 移動、縮放、改樣式，雙擊文字可編輯 |
| 裁切 | `C` | 自由或固定比例，`Enter` 套用 |
| 箭頭／直線 | `A` / `L` | `Shift` 鎖定 45° 角 |
| 方框／橢圓 | `R` / `O` | 可填滿，`Shift` 畫正方形或正圓 |
| 畫筆／螢光筆 | `P` / `H` | `Shift` 畫直線 |
| 文字 | `T` | 支援多行與標籤底色 |
| 步驟編號 | `N` | 自動遞增，刪除後重新編號 |
| 塗黑 | `X` | 用實色完全覆蓋 |
| 馬賽克／模糊 | `M` / `B` | 遮住較不敏感的內容 |
| 聚光 | `S` | 框選區域以外變暗 |

「影像」選單另有旋轉、翻轉、調整尺寸、邊框與圓角。按 `?` 可查看完整快捷鍵。

> 密碼、金鑰等機密資料請用**塗黑**。馬賽克和模糊在部分情況下可能被還原或辨識。

## 開發

純靜態網站，沒有相依套件，也不需要建置。

```sh
python3 -m http.server 8000
```

然後開啟 <http://localhost:8000>。剪貼簿 API 需要 HTTPS 或 localhost。

## 部署

推送到 `main` 後由 GitHub Pages 發布：repo 的 **Settings → Pages → Deploy from a branch**，選 `main` 分支和 `/ (root)`。
